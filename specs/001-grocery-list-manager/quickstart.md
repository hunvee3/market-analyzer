# Quickstart: Grocery List Manager (Frontend)

**Branch**: `001-grocery-list-manager` | **Date**: 2026-03-27

## Prerequisites

- Node.js 22+
- npm 10+ (or pnpm 9+)

```bash
cd frontend
npm install
```

## Run Development Server

```bash
npm run dev
```

Opens at `http://localhost:5173`. Hot module replacement is active.
Dark/light mode toggle is available in the app header.

Mock data is persisted to localStorage under keys:
- `smart-basket:v1:grocery-lists`
- `smart-basket:v1:categories`

To reset all mock data:
```javascript
// Run in browser console
localStorage.removeItem('smart-basket:v1:grocery-lists');
localStorage.removeItem('smart-basket:v1:categories');
location.reload();
```

## Run Tests

```bash
# Run all unit tests
npm test

# Watch mode
npm run test:watch

# Coverage report
npm run test:coverage
```

Tests are located in `tests/unit/` mirroring the `src/` structure.
All port dependencies are mocked via `vi.fn()` — no localStorage is accessed in unit tests.

## Build PWA

```bash
npm run build
npm run preview  # preview production build locally
```

The production build outputs to `frontend/dist/`. The service worker and manifest are
auto-generated by `vite-plugin-pwa`.

## Architecture Quick Reference

```
Presentation (React components, Jotai atoms)
    ↓ calls use cases; updates atoms
Application (use cases, port interfaces)
    ↓ calls port methods
Infrastructure (LocalStorage adapters)
    ↓ reads/writes
localStorage
```

To swap to the real backend adapter when it's ready:
1. Add `HttpGroceryListRepository` and `HttpCategoryRepository` in `infrastructure/`
2. Update `src/di/container.ts` to inject the HTTP adapters instead of LocalStorage
3. No other files change.
